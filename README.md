🌍 Tourism Management System

A web-based Tourism Management System that helps users explore tourist destinations and book trips easily.

✨ Features

- View tourist destinations
- Search for destinations
- Book trips online
- View booking details in My Bookings
- Responsive user interface
- Local destination images

🛠️ Technologies Used

Frontend: HTML, CSS, JavaScript
Backend: Java, Spring Boot
Database: PostgreSQL
Tools: VS Code, Eclipse, pgAdmin, Postman

🚀 How to Run

1. Clone or download this repository.
2. Open the frontend folder in VS Code.
3. Run the Spring Boot backend from Eclipse.
4. Start PostgreSQL and connect the "tourism_db" database.
5. Open "index.html" in your browser.
